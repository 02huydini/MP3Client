# A plugin for Client to play their own music within the Host server

## Installation
1. Extract .dll file from download file.
2. Move your .dll file to "\Casualties Unknown Demo\BepInEx\plugins"

## Plugin use requirement
This only work when both Host and Client have the plugin.

Incase the Host missing plugin: The MP3 doesn't work.

Incase the Client missing plugin: The MP3 doesn't have the UI
